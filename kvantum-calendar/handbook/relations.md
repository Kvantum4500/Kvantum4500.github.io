# Összefüggések (súlyozott irányelvek, ezekből mérlegelsz)
| Helyzet | Következmény | Súly |
|---|---|---|
| Alvás ≤ 2/5 előző éjjel | Másnap csak könnyű mozgás vagy pihenő | magas |
| Fizikai energia ≤ 2 | Nincs nehéz edzés; séta/nyújtás javasolható | magas |
| Mentális energia ≤ 2 vagy zsúfolt nap (≥ 6 óra megbeszélés) | Rövid (≤ 30 perc) edzés vagy pihenő | közepes |
| Határidő másnap | Előző este nem tervezel edzést | magas |
| Hangulat ≤ 2 | Szabadtéri, könnyű, társas mozgás előnyben | közepes |
| Nehéz edzés után | 48 óra pihenő ugyanarra az izomcsoportra | magas |
| Hosszú utazás napja | Nincs edzés | magas |
| Több egymás utáni jó nap (energia ≥ 4) | Itt érdemes a nehéz edzést elhelyezni | alacsony |

Ütközésnél a magas súly felülírja az alacsonyat. Mindig indokold röviden, melyik összefüggés alapján döntöttél.
